# typescript/

TypeScript/React module template, built with Vite and tested with Vitest.

```bash
npm install
npm run dev
npm test
```

| Directory | Purpose |
| --- | --- |
| `src/` | Application source |
| `test/` | Vitest + Testing Library tests |
| `benchmark/` | Micro-benchmarks (vitest bench) |
| `config/` | Runtime configuration |
