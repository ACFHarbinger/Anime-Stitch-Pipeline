Anime Stitch Pipeline

High-performance C++ and Python panorama stitching core for anime panning shots. Incorporating 2D $[t_x, t_y, s]$ motion estimation, Graduated Non-Convexity (GNC-TLS) robust residual weighting, character cel seam exclusion barriers ($1\text{e}9$), and dynamic keyframe selection.

C++20 Core GNC-TLS Solvers 702 Verified Tests
STAGE 01

2D $[t_x, t_y, s]$ Motion Model

Constrains homography estimation to pure lateral pan and scale $[t_x, t_y, s]$, eliminating homography rotational warping and image stretching across anime cel pans.

STAGE 02

GNC-TLS Outlier Rejection

Graduated Non-Convexity Total Least Squares iteratively dampens feature matches along moving ink outlines, guaranteeing stable global bundle adjustment.

STAGE 03

Character Cel Seam Barrier

Applies a $1\text{e}9$ C++ cost exclusion barrier along foreground character masks during Min-Cut/Max-Flow DP seam calculation, preventing torn anatomy.
