# kotlin/

Kotlin/JVM module template, built with Gradle Kotlin DSL.

```bash
./gradlew build
./gradlew test
./gradlew ktlintCheck
```

| Directory | Purpose |
| --- | --- |
| `src/main/kotlin/` | Application source |
| `src/test/kotlin/` | JUnit 5 tests |
| `benchmark/` | JMH-style micro-benchmarks |
| `config/` | Runtime configuration |
